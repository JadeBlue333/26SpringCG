# CandyJar Three.js Art

A minimal Three.js + Vite starter for creating interactive generative artwork.

## Getting started

1. Open the workspace in terminal.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Notes

- `src/main.js` contains the scene, camera, lighting, and interactive wave surface.
- Move the mouse pointer to influence the mesh wave and lighting.
